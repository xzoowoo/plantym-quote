견적 도구, 누가 사용하나요?

이 질문이 전체 설계 방향을 결정합니다

A

내가 직접 사용 (내부 도구)

업체와 미팅하면서 내가 직접 입력하고 견적을 뽑아냄.
업체는 결과(견적서)만 받아봄.

B

업체가 직접 입력 (외부 공개)

업체에 링크를 보내면 업체가 직접 요구사항을 입력함.
입력 완료 후 견적이 자동으로 산출됨.

C

둘 다 (상황에 따라)

미팅 때는 내가 입력하고, 원격 업체에는 링크를 공유함.
두 방식 모두 지원.
