# 영상 제작 견적 생성기 — 설계 문서

**날짜:** 2026-05-14  
**프로젝트:** 플랜티엠 콘텐츠 제작 견적 생성 웹앱

---

## 1. 개요

영상 디자이너가 업체별 맞춤 견적을 빠르게 산출하기 위한 웹 애플리케이션.  
내부 단가표(`플랜티엠_콘텐츠제작단가표_260126.xlsx`)를 기반으로 항목을 자동 계산하고, Claude AI가 자유 입력 텍스트를 분석해 항목을 자동 추가한다.

---

## 2. 사용자 및 사용 시나리오

- **주 사용자:** 내부 디자이너 (견적 산출 담당)
- **시나리오 A:** 디자이너가 직접 입력 → 내부 원가 확인 + 외부 PDF 출력
- **시나리오 B:** 미팅 시 업체 담당자가 직접 브라우저에서 입력 → 견적 결과 화면 확인

---

## 3. 화면 흐름 (6단계 위저드)

### Step 1 — 기본 정보
- 업체명 (텍스트)
- 담당자명 (텍스트)
- 프로젝트명 (텍스트)
- 견적일 (날짜 선택, 기본값: 오늘)

### Step 2 — 패널 정보
- 패널 수 (숫자 입력)
- 패널 사이즈/규격 (텍스트, 예: "55인치", "1920×1080")
- 비디오월 여부 (토글): 멀티패널 동기화 모션 필요 시 선택

### Step 3 — 콘텐츠 유형 (복수 선택)
- 이미지 제작 (기존 소스 편집)
- 영상·모션 제작
- AI 이미지 생성
- AI 영상 생성

### Step 4 — 세부 요청사항 (Step 3 선택에 따라 동적 표시)

**이미지 제작 선택 시:**
- 이미지 보유 여부: 보유 있음 / 제작 필요 (리서치 포함)
- 총 이미지 수 (숫자)
- 편집 작업 체크박스 (복수 선택):
  - 사이즈/비율 변경
  - 배경 제거 (누끼)
  - 소스 분리 (레이어)
  - 비율 재배치 (가로↔세로)
  - 합성
  - 텍스트 추가
  - 디자인 요소 추가

**영상·모션 선택 시:**
- 영상 길이 (초 단위 숫자)
- 컷 편집 필요 여부
- 자막 필요 여부
- 이미지/영상 롤링 여부 (장 수)
- 화면전환: 없음 / 기본 / 고급
- 등장효과: 없음 / 기본 / 고급 (건 수)
- 강조효과: 없음 / 기본 / 고급 (건 수)
- 특수효과: 없음 / 기본 / 고급 (건 수)
- 애니메이션: 없음 / 기본 / 고급 (건 수)
- 출력 품질: Full HD / 4K 이상
- USB 변환 필요 여부

**AI 이미지 생성 선택 시:**
- 생성 건수 (숫자)

**AI 영상 생성 선택 시:**
- 생성 건수 (숫자)

**공통 — 자유 입력 (AI 분석):**
- 텍스트 영역: 추가 요청사항 자유 입력
- "AI 분석" 버튼 클릭 시 Claude API가 텍스트를 분석해 누락 항목 자동 추가 및 제안

### Step 5 — 마진 설정
- 마진율(%) 숫자 입력 (기본값: 0)
- 원가 → 마진 포함 최종 견적가 실시간 미리보기

### Step 6 — 견적 결과

**내부 화면 (A형):**
| 구분 | 작업 항목 | 기준 | 수량 | 원가 | 합계 |
|------|-----------|------|------|------|------|
| 이미지 | 소스 리서치 | 1건 | 1 | 23,505 | 23,505 |
| ... | ... | ... | ... | ... | ... |
- 원가 소계
- 마진 금액 (마진율 × 원가)
- **최종 견적가**
- "PDF 다운로드" 버튼

**외부 PDF (B형):**
- 업체명, 담당자, 프로젝트명, 날짜
- 카테고리 요약만 (이미지 제작 / 영상·모션 / AI 생성)
- 최종 견적가 (VAT 별도 명시)
- 회사 정보 (로고 영역)
- 세부 단가 비노출

## 5. AI 분석 기능

- 사용 모델: Claude claude-haiku-4-5 (속도/비용 최적)
- 입력: 사용자 자유 텍스트
- 출력: 매핑된 단가 항목 목록 (JSON)
- 프롬프트: 내부 단가 항목 목록을 컨텍스트로 제공 → 텍스트에서 해당 항목과 수량 추출
- 결과는 사용자가 검토 후 확정 (자동 추가 + 수동 수정 가능)

| 역할 | 기술 |
|------|------|
| 프레임워크 | Next.js 14 (App Router) |

## 8. 비기능 요구사항

- 모바일 반응형 (미팅 시 태블릿/폰으로도 사용 가능)

- PDF에는 개별 단가 미표시
- Vercel 무료 플랜 한도 내 운영 가능
