# 견적 화면 개선 (기획 항목 / 산출근거 / 항목 설명 / 패널 사이즈) 설계

## 배경

사용자가 실제 사용해보면서 발견한 4가지 개선 요청. 각각 대화를 통해 방향을 확정했다. (참고로 5·6번 — 견적 저장/불러오기 + 사이드바 — 은 별도 규모라 이 스펙에서 제외하고 후속으로 다룬다.)

## 1. 기획 및 프롬프트 설계 항목

### 문제
`RATES.ai.image`/`RATES.ai.video`의 작업비에는 "기획·리서치"와 "프롬프트 엔지니어링" 단계가 이미 녹아있지만, 화면에는 "AI 이미지 생성"/"AI 영상 생성" 한 줄로만 보여서 안 보인다. AI를 전혀 선택하지 않은 견적(이미지/영상만)에는 기획 비용 자체가 존재하지 않는다.

### 결정
- **기획 및 리서치**: 콘텐츠 유형을 하나라도 선택하면 항상 포함되는 별도 항목(1식, 188,040원). AI 사용 여부와 무관.
- **프롬프트 설계**: `ai-image` 또는 `ai-video`를 하나라도 선택했을 때만 추가로 포함되는 별도 항목(1식, 141,030원).
- 두 항목 모두 새 `category: "planning"`으로 묶는다 (내부용 화면에서 "기획" 그룹으로, 외부용 화면에서 "기획 및 설계" 그룹으로 표시).
- `RATES.ai.image`/`RATES.ai.video`의 작업비에서 기획·프롬프트 단계 금액을 제외한다 (중복 계산 방지):
  - `RATES.ai.image.cost`: 39,175 → **15,670** (생성·선별 3,917.5 + 후보정·합성 11,752.5)
  - `RATES.ai.video.cost`: 5,030,070 → **4,701,000** (생성·선별 1,880,400 + 후보정·합성 2,820,600)
  - `usageFee`는 변경 없음 (1,300 / 1,072,800)
- 두 새 항목은 예상 제작일정 배율 계산에서 **배율 적용 대상**(scalable)이다 — AI 솔루션 사용료만 고정.

## 2. 내부용 화면 하단 산출근거

내부용 화면(`QuoteTable.tsx`)과 내부용 PDF(`PDFDocumentInternal.tsx`) 하단에 아래 문구를 고정 표시:

> 산출 근거: 기준 단가 188,040원/일(8시간 기준), 23,505원/시간 · 난이도 가중치 하 1.0 / 중 1.5 / 상 2.0 · 근거: 한국디자인산업연합회(KODIA) 2025년 산업별 노임단가표

`input.expectedScheduleDays`가 설정된 경우, 아래 문구를 추가로 표시:

> 본 견적은 예상 제작일정 N일 기준으로 항목별 금액이 비율에 맞춰 재조정되었습니다.

이를 위해 `QuoteTable`이 `input`(또는 최소 `expectedScheduleDays`)을 받도록 props를 확장한다.

## 3. 항목별 설명(?) 아이콘

4단계(세부 요청사항) 화면의 작업 항목 라벨 옆에 작은 `?` 아이콘을 추가하고, 클릭하면 라벨 아래에 짧은 설명이 뜨는 재사용 컴포넌트(`InfoTooltip`)를 만든다. 적용 대상: 이미지 편집 작업 7종, 영상 체크박스(컷 편집/자막 삽입/USB 변환/롤링), 모션 효과 5종(화면전환/등장효과/강조효과/특수효과/애니메이션), 출력 품질. 설명 문구는 비개발자가 이해할 수 있는 쉬운 문장으로 작성한다.

## 4. 패널 사이즈 "기타"

- 라벨 변경: "기타 (직접입력)" → "기타 사이즈"
- 실제 동작하는 커스텀 입력 칸 추가: "기타 사이즈" 선택 시 `PanelInfo.size`를 빈 문자열로 바꾸고, 프리셋 목록에 없는 값이면 직접입력 칸을 보여줘서 사용자가 실제 사이즈(예: "70인치")를 입력할 수 있게 한다. 기존 "다음" 버튼 활성화 조건(`value.size.trim()`)이 그대로 빈 값 방지 역할을 한다.
